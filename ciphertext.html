Cipher Tips

  • Use a phrase key for Vigenere; avoid numbers and symbols.
  • Caesar shifts move letters by a fixed amount; try 3 for classic text.
  • Rail Fence uses zig-zag rows; the depth controls the rails.
  • XOR works on bytes; keep the key short but not empty.
  • AES uses a random salt and IV. Keep the full CipherApp AES v1 output with your passphrase.
  • Classical ciphers and encodings are for learning, not secure communication.

Batch Transform

Transform up to 100 messages with the selected modes and key. Enter one message per line; blank lines are ignored. Results stay in this browser session.

How batch processing works

  1. Put one message on each line. Empty lines are skipped.
  2. Choose the From and To modes and enter any required key once; those settings are applied independently to every message.
  3. Run the batch to see each result or its own error. Up to 100 non-empty messages can be processed at a time.
  4. Copy or download the JSON results when needed. For AES, each message is encrypted separately with a fresh salt and IV.

Inputs and results stay in page memory unless you copy or download them. Treat exported files as sensitive if they contain private messages.
