CipherLab

A private workspace for transforming messages, converting number bases, and calculating directly across numeral systems.

Start with a tool

  1. Choose a workspace and enter your text or numbers.
  2. Set the cipher or bases, then run the transformation.
  3. Review and copy the result when you’re ready.
Cipher Text Transform messages individually or in batches of up to 100 lines. Number Converter Convert values individually or in batches between bases 2–36 and Base64. Number Calculator Evaluate expressions across number systems. Text Encoding Inspector Inspect Unicode code points and their UTF-8 bytes. Hash & Verify Generate SHA-2 hashes for text or files and verify data against a known digest.
