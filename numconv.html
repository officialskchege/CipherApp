Number Conversion Tips

  • Binary uses only 0 and 1.
  • Octal digits range from 0 to 7.
  • Hexadecimal uses 0–9 and A–F.
  • Digits above 9 are represented by letters A–Z.
  • Base 64 uses A–Z, a–z, 0–9, +, / and padding =.
  • Use "Swap bases" to quickly reverse conversions.

Number System Converter

Convert numeric values between bases without leaving the CipherApp layout. Select the source base and target base, enter a number, and get a formatted conversion instantly.

Input

Enter a number using the source base. You may include spaces or underscores for readability.

Convert

Convert a number between bases, swap the source and target, clear the field, or copy the result to your clipboard.

Supports bases 2 through 36. Letters A–Z represent values 10–35. Base 64 here treats bytes as an unsigned integer. For ordinary text, use the separate Base64 Text tool below. Leading zero bytes are retained when converting directly between Base64 and binary, octal, or hexadecimal.

Result

Batch Convert

Convert up to 100 values using the selected bases. Enter one value per line; blank lines are ignored. Results stay in this browser session.

How batch processing works

  1. Put one value on each line. Empty lines are skipped.
  2. Choose the source and target bases once; the same conversion settings are applied independently to every value.
  3. Run the batch to see each converted value or its own error. Up to 100 non-empty values can be processed at a time.
  4. Copy or download the JSON results. Base64 here means integer bytes; use the separate Base64 Text tool for UTF-8 text.

Inputs and results stay in page memory unless you copy or download them.
